## Full description (README / portfolio / LinkedIn post)
Translator App v20 is Project #04 of my 100+ AI Projects series — built advanced from the start, never a basic v1.

It translates English, Hindi, Bengali, Spanish, French, German, Japanese, Tamil and Telugu, with a swap button, speak for input and output, copy/share, favourites and history. Online it uses the free MyMemory API with no key. If that free quota finishes or internet fails, it does not invent an answer — common phrases and common words still translate offline from a built-in phrase book, and the app tells you which source it used. It works as an installable phone app, and the Python version has the exact same v20 logic.
